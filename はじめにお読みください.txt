blnext（BeatLeader 次回プレイリスト生成ツール）
================================================

BeatLeader の公開データから「次に遊ぶと総PP が伸びそうな曲」を選んで、Beat Saber のプレイリストにする Windows 用のアプリです。

■ 使い方
1. この zip を、好きな場所に展開します（Program Files の中など、書き込めない場所は避けてください）。
2. blnext.exe を起動します。
   「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください（個人が作ったアプリで、コード署名をしていないためです）。
3. 「はじめに」の小さな画面で、BeatLeader の表示名か ID を入れて自分を選びます（ログインは要りません）。
4. データの取得に 1 分ほどかかります。終わると、難しさ違い（着実・標準・チャレンジング）の 10 曲ずつのプレイリストができます。
5. 「Beat Saber に書き込む」か「BSManager で入れる」でゲームに入れて遊びます。
6. 遊んだ後にアプリを開くと、結果をホームで振り返れて、次のリストも作り直せます。

■ 必要な物
- Windows 11（画面に Microsoft Edge WebView2 を使います。Windows 11 には入っています）
- ゲームの中でプレイリストを読むための Mod「PlaylistManager」
- BeatLeader のアカウントと、ランク曲のスコア（スコアが無いとプレイリストを作れません）

■ 統計の公開（おすすめ）
BeatLeader の統計が非公開だと、失敗や途中でやめた挑戦の記録を読めないので、クリアの見込みと、同じ曲を続けて出さない働きが効きません。
beatleader.com にログイン → 設定の Scores → Score history の Public history をオンにしてください（無料で変えられ、いつでも戻せます）。
オンにすると、挑戦の回数や失敗した記録、遊んだ日時をほかの人も見られるようになります。順位や PP は変わりません。
非公開のままだと、プレイリストを作る・出すたびに警告が出ます（設定の「通信」にある「統計が非公開の時に警告する」で止められます）。

■ データの場所
設定と取得したデータは、blnext.exe の隣の config・data・logs・exports に置きます。インストーラーはありません。消す時はフォルダごと消してください。
通信するのは、BeatLeader（公開 API にプレイヤーの ID を送ります。自己ベストのリプレイの先頭も読みます）・BeatSaver の CDN（曲の画像）・jsDelivr（ランク譜面の変化を確かめる公開のファイル）・GitHub（新しい版の確認と更新のダウンロード）だけで、あなたのデータをどこかへ送ることはしません。

■ 困った時・不具合の報告
- blnext.exe をもう一度開くと、開いている窓が前に出ます（同じフォルダの blnext は 1 つしか開けません）。
- 画面が出ない・真っ白な時は、Microsoft Edge WebView2 ランタイムが入っているか確かめてください。
- 起動しない時は、ダウンロードした zip を右クリック →「プロパティ」→ 下の「許可する」にチェック →「OK」としてから、展開し直してください
  （インターネットから来たファイルの印が残っていると、部品を読み込めないことがあります。アプリも起動の最初に外していますが、念のため）。
- 動かない・おかしい時は、設定 → このアプリについて →「不具合を報告」で GitHub の Issues のページが開きます（GitHub のアカウントが要ります）。
  アプリの版と Windows の版は自動で入ります。起きたことと、その前にした操作を書いてください。
- 同じ所の「ログのフォルダを開く」で開く logs の中のファイルを添えてもらえると、原因を調べやすくなります。
  ログには BeatLeader に問い合わせた URL（あなたのプレイヤー ID）と、失敗した時はこのアプリのフォルダの場所が入ることがあります。
- アプリが開かない時は、直接 https://github.com/Oz-Co-two/blnext/issues へ。logs のフォルダは blnext.exe の隣にあります。

■ 更新
新しい版があると起動した時に知らせます。「更新する」を押すと、アプリの中から更新できます（設定とデータはそのまま残ります）。
更新の前の版は _previous_<版> のフォルダに 1 世代だけ残ります。
